# Purulia Story Map

Interactive nature, culture and heritage story map of Purulia, West Bengal.

Features:
- Hills, waterfalls, dams, forests, cultural villages, archaeological sites and temples
- Real/public web photographs with satellite fallback
- Search and category filtering
- Normal and satellite basemaps
- My Location, road distance, estimated time and Google Maps navigation
- Responsive story panel

Created by **Soumen Pal** — Remote Sensing & GIS.
